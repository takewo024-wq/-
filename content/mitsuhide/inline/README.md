# 本文挿入画像(章扉バナー)

各話の本文中、節の見出しの直前に挿入するセクション区切り画像。noteでは見出しの上に画像を置くと章扉のように使える。サイズは 1280×440(実ファイルは2倍解像度)。アイキャッチと同じ意匠(藍×墨×金・桔梗紋の透かし)で統一。番組の映像・写真は不使用、モチーフはSVGで自作。
