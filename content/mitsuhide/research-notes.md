# 明智光秀 考証メモ(担当: 榊原)

シリーズ「明智光秀 — 謎だらけの生涯」執筆用の調査資料。**[確実]** = 一次史料・同時代史料で裏付けあり / **[有力]** = 通説として広く支持 / **[諸説]** = 説が分かれる / **[伝承]** = 後世の逸話・軍記物由来(創作の可能性が高い)。

## 「放送ではわからない」重点ポイント

1. **前半生がほぼ空白**: 織田家中の出世頭なのに、40代(推定)までの人生が史料でたどれない稀有な大物。
2. **初出史料が「薬の本」**: 武功ではなく医術の口伝で歴史に登場する意外性。2014年発見という新しさもフックになる。
3. **越前の10年**: 称念寺門前の牢人暮らし。妻・妻木煕子が黒髪を売って連歌会の費用を工面した逸話(芭蕉の句「月さびよ明智が妻の咄しせん」で有名)は**江戸期の伝承**であり、史実と区別して紹介すること。
4. **義昭と信長への「両属」**: 単純な「信長の家臣」ではなく、幕府と織田の間に立つ調整役として台頭した点は近年の研究の強調点。

## 有料回(第2〜4回)用の調査続き

- 第2回: 坂本城、丹波攻略、惟任日向守、家中での地位(近畿方面軍)
- 第3回: 本能寺の変の動機諸説(怨恨説・野望説・四国説・黒幕説の史料状況。四国説は近年有力視 — 長宗我部問題)
- 第4回: 山崎の戦い、小栗栖での最期[有力]、生存・天海説[伝承]、娘・細川ガラシャと子孫のその後
