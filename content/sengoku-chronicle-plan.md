# 戦国クロニクル製作会社 — 事業計画メモ

## コンセプト

放送中の大河ドラマ「豊臣兄弟」で注目が高まっている戦国武将のうち、**主人公(豊臣秀長)以外の武将を毎回一人ずつ**取り上げ、**「放送ではわからない生涯」**(生い立ち、転機、逸話、最期、子孫のその後など)を深掘りする連載コンテンツを製作・販売する。

## 販売モデル

- 各武将シリーズの**第1回は無料**公開して読者を集める
- **第2回以降は有料**販売(単話・シリーズまとめ買い・月額マガジンを販売担当が設計)
- 無料回の末尾に「続きが読みたくなる引き」+ 購入導線を必ず置く

## 候補武将ラインナップ(例)

豊臣秀吉 / 織田信長 / 徳川家康 / 明智光秀 / 柴田勝家 / 前田利家 / 黒田官兵衛 / 竹中半兵衛 / 蜂須賀小六 / 浅井長政 / 石田三成 など。放送の展開に合わせて「今まさに登場している武将」を優先する。

## 制作フロー

1. 大森(プロデューサー)と武将・回数構成を決める
2. 榊原(考証)に調査を依頼 → 年表とエピソード候補を受け取る
3. 早川(ライター)に第1回(無料)から順に執筆を依頼
4. 三好(販売)に販売ページ・価格・告知文を依頼して公開

## 権利上の厳守事項

- 史実・歴史資料(パブリックドメイン)に基づく**オリジナルコンテンツ**として製作する
- NHKの映像・脚本・ナレーション・タイトルロゴ・出演俳優の写真や名前は**一切使用しない**
- 番組の公式・公認と誤認される宣伝をしない(「ドラマで話題の武将」程度の言及にとどめる)
