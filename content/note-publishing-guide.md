# note 入稿ガイド(戦国クロニクル)

このリポジトリの成果物を note で公開するための手順書。**note は独自HTML/CSSを貼れない**ため、デザインした一覧ページ(`content/catalog/`)は「記事」にはできない。noteでの「一覧」は **クリエイターページ + マガジン** で実現する。下表のとおり対応づける。

## 貼り付け用データの場所(準備済み)

- **`content/note-ready/*.txt`** … 各記事の **note貼り付け用テキスト**。上部の「入稿メモ」枠(タイトル・画像・価格・見出しにする行・有料ライン位置)を見ながら、`▼▼▼ ここから下を本文にコピー ▼▼▼` 以降を本文欄に貼り、メモに従ってツールバーで見出し/引用/有料ラインを設定するだけ。Markdown記号は除去済み。
- **`content/catalog/standalone.html`** … 一覧ページの**単体HTML版**(1ファイル完結)。GitHub Pages 等に置けばそのまま公開できる。`content/catalog/index.html` はClaudeのArtifact用。

### 現在の執筆状況

**全8本そろっている**:明智光秀 第1〜4回、黒田官兵衛 第1〜4回。それぞれ本文・アイキャッチ・note貼り付け用テキストが用意済み。公開スケジュール上は光秀シリーズ(第1回=7/12公開予定)を先に、官兵衛シリーズを後続で入稿するのが順当。

## 成果物 → note機能の対応

| 作ったもの | noteでの置き場所 |
| --- | --- |
| 各話の本文(`content/*/ep*.md`) | 記事(第1回=無料note、第2回以降=有料note) |
| アイキャッチ(`content/thumbnails/*.png`) | 各記事の見出し画像(1280×670。noteの推奨サイズに一致) |
| シリーズ(光秀/官兵衛) | マガジンを1本ずつ作成し、そのシリーズの4記事を追加 |
| まとめ買い¥700 | 第2〜4回を入れた「有料マガジン(単体買切)」 |
| 月額¥500 | 月額マガジン(※要申請・下記の前提を参照) |
| 一覧ページ(`content/catalog/standalone.html`) | note内には置けない。GitHub Pages等で公開し、プロフィール文や記事末尾から**外部リンク**として貼る |
| 販売文・SNS文(`content/*/promo.md`) | 記事冒頭のリード、マガジン説明文、Xでの告知にそのまま流用 |

## 公開前の前提(最初に1回だけ)

1. **売上を受け取る設定**: 有料noteを売るには、note設定で本人確認情報と振込口座の登録が必要。これが未完了だと価格を付けられない。
2. **月額マガジンは申請制**: 誰でもすぐ作れるわけではない(一定の条件・審査がある)。使えない場合は、まず「単体有料note + まとめ買い用の有料マガジン」で始め、月額は後から追加する。最新の条件はnoteのヘルプで確認する。

## 1記事の入稿手順(無料の第1回)

1. note で「投稿 → 記事」を開く。
2. 見出し画像に該当の `*-ep1.png` をアップロード。
3. 本文 `ep1-free.md` の中身を貼り付ける。noteはMarkdown記号を自動変換しないので、貼った後に:
   - `##` の行 → ツールバーで「見出し」に設定
   - `>` の引用 → 「引用」に設定
   - `---` → 「区切り線」を挿入
   - `**強調**` → 太字に設定
   （最初の1本だけ整えれば、以降はコピー元の構造が同じなので流用が速い)
4. 価格は「無料」のまま。
5. 公開設定でハッシュタグを付ける(下記)。
6. 公開後、作成したマガジンに追加する。

## 1記事の入稿手順(有料の第2〜4回)

1. 上と同じ要領で見出し画像と本文を入れる。
2. 記事の「冒頭のあらすじ+つかみ」までを無料で読ませ、その直後に **有料エリアの区切り線** を置く(本文中で「前回までのあらすじ」の直後あたりが目安)。以降が購入者だけに見える。
3. 価格を **¥300** に設定(要・振込口座登録)。
4. 公開 → シリーズのマガジンに追加。

## まとめ買い(¥700)の作り方

- マガジンを1本作り、**有料(単体買切)¥700** に設定して第2〜4回を追加する。
- 単話合計¥900に対して¥700なので「まとめると2話分の値段で3話」という訴求になる(`promo.md` のリード文を説明欄に転用)。

## 一覧ページ(catalog)の公開 — GitHub Pagesの手順

noteの記事にはできないので、単体HTMLを外部で公開してリンクする。GitHub Pagesが手軽:

1. `content/catalog/standalone.html` をリポジトリの `docs/index.html` にコピーする(Pagesは各ブランチの直下か `docs/` しか配信できないため)。
2. このブランチを既定ブランチ(main)にマージする。
3. GitHubのリポジトリ設定 → Pages → Source を「main / docs」に設定して保存。
4. 数十秒後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される。そのURLをnoteのプロフィールや各記事末尾に貼る。

※ Pagesの有効化はGitHub上の操作が必要(こちらから自動では有効化できない)。`docs/` へのコピー自体は依頼あれば用意する。

## 権利面(公開前チェック)

- タイトル・本文・説明文・タグに **番組名・俳優名・「大河ドラマ」を入れない**(「日曜夜の歴史ドラマで注目の」等に言い換え済み)。
- 各記事末尾の「特定の放送番組とは関係ありません」の一文を残す。
- 見出し画像は自作。番組の画像・ロゴ・出演者写真は使わない。
