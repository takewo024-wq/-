# ホームページ制作の方針メモ（介護施設サイト）

このメモは、介護施設のホームページを作るときの「約束ごと」を、職員の方が読んで分かるように
まとめたものです。作業を担当するClaudeも、このメモと `AGENTS.md` の内容に従って作ります。

最終更新：2026-11-22

---

## 1. 何を参考にするか

- お手本サイト：**社会福祉法人やまと園**　https://www.yamatoen.or.jp/
- 参考にするのは「**デザインの型**」だけです。たとえば──
  - ページの並び順（例：お知らせ → サービス紹介 → 採用案内 → アクセス）
  - 余白の取り方、文字の大きさ、見やすい色の使い方
  - 介護施設サイトによくあるセクションのレイアウト

> たとえ話：他の施設の掲示物の「見やすい貼り方」をお手本にするのはOK。
> でも、その施設の写真やロゴをコピーして自分の施設の名前で貼り出すのはNG。これと同じ考え方です。

---

## 2. やってはいけないこと（相手への配慮・法律の面）

参考サイトは「見て学ぶ」だけにします。次のことはしません。

- 写真・イラスト・ロゴを**ダウンロードして使う**（著作権・商標の侵害になり得ます）
- 理念やあいさつ文などの**文章を丸写しする**
- 相手サイト独自の**配色やブランドをそっくり真似る**

### 相手に迷惑や通知は行く？
- サイトを**見るだけ**なら、相手に通知は届きません。負担もかかりません。
- 通知が行くのは「問い合わせフォーム送信・メール・SNSのタグ付け」などをした場合だけで、
  今回はそれらは**一切しません**。

---

## 3. 必ずやること

- 完成するサイトの**写真・文章・ロゴ・色は、100%この施設オリジナル**にします。
- 専門用語は、そのつど分かりやすい言葉に置きかえて説明します。

---

## 4. 技術メモ（作る人向け）

- このプロジェクトは **Next.js 16 / React 19 / Tailwind CSS v4** で動いています。
- トップページの中身は `src/app/page.tsx`。
- Next.js はバージョンが新しく従来と書き方が違うため、コードを書く前に
  `node_modules/next/dist/docs/` の該当ガイドを必ず確認します（`AGENTS.md` の指示）。
- 参考サイトを直接見る必要が出たら、作業開始時に
  `www.yamatoen.or.jp` へのネット接続許可をユーザーに確認してから参照します。
