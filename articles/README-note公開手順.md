# 「姉川の合戦」note公開手順

このフォルダの素材を使って、note記事を下書き公開するまでの手順。

## 使うファイル

| ファイル | 用途 |
|---|---|
| `anegawa-no-tatakai-note-draft.md` | 記事本文（コピペ用） |
| `images/anegawa-fujin-zu.png` | 布陣図（本文中に挿入） |
| `images/anegawa-thumbnail.png` | サムネイル（記事トップ画像） |
| `anegawa-intro-text.md` | 紹介文（記事の説明欄用） |

## 手順

1. **noteで新規記事を作成**
   - 記事作成画面を開く

2. **本文をコピペ**
   - `anegawa-no-tatakai-note-draft.md` の中身を全文コピーし、本文欄に貼り付け
   - 冒頭の `# 姉川の合戦――...` の見出し行を、記事タイトル欄にも入力

3. **布陣図を挿入**
   - 本文中の `（★ここに anegawa-fujin-zu.png を画像として挿入★）` という行を探す（「4. 略図でみる布陣」の章）
   - その行を削除し、同じ位置に `images/anegawa-fujin-zu.png` を画像としてアップロード・挿入

4. **サムネイルを設定**
   - 記事のトップ画像（サムネイル）設定欄に `images/anegawa-thumbnail.png` をアップロード

5. **紹介文を貼り付け**
   - 「概要（説明文）」欄に、`anegawa-intro-text.md` の「メイン案」をコピペ：
     ```
     元亀元年、信長を挟撃した浅井長政の裏切りと、九死に一生を得た「金ヶ崎の退き口」。そして雪辱の姉川決戦へ――。義理と愛に引き裂かれた戦国屈指のドラマを、背景・合戦の全経過・布陣図つきで徹底解説。現地案内と、夏の夜に語りたい少し怖い話も。
     ```

6. **下書き保存**
   - 内容を確認し、「下書き保存」をクリックして完了

## 補足
- note.com への自動投稿・API連携はこのセッションでは未対応のため、上記はすべて手動での貼り付け作業となる。
- 布陣図・サムネイルのソースは `images/anegawa-fujin-zu-canva.html` ／ `images/anegawa-thumbnail.html`。デザイン変更が必要な場合はこのHTMLを編集し、Chromiumで再レンダリングして差し替え可能。
